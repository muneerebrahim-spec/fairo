# FairSplit

A simple, beautiful bill splitting app. Add people, record expenses, and see exactly who owes whom.

## Features

- Add and remove participants
- Record expenses with payer and split participants
- Equal split among selected people
- Live balance calculations
- Suggested minimum settlements to settle up

## Tech stack

- React 19 + TypeScript
- Vite
- Tailwind CSS 4

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

## Scripts

| Command         | Description              |
| --------------- | ------------------------ |
| `npm run dev`   | Start development server |
| `npm run build` | Production build         |
| `npm run preview` | Preview production build |
